html

html is a markup language used to create web pages. It provides the structure and content of a webpage, such as headings, paragraphs, images, and links.

css

css is a style sheet language used to describe the presentation of a document written in html. It controls the layout, colors, fonts, and other visual aspects of a webpage.

js

js is a scripting language used to add interactivity and dynamic behavior to web pages. It allows developers to create interactive elements, handle events, and manipulate the content of a webpage.
